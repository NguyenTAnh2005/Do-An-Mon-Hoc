title Sơ đồ Tuần tự 2: Giám sát Mức đầy Realtime & Trạng thái Online/Offline (LWT)

participant "Vi điều khiển\nESP32" as ESP
participant "MQTT Broker\n(Mosquitto)" as Broker
participant "Backend API\n(FastAPI)" as Web
database "PostgreSQL" as DB
participant "Frontend\n(ReactJS)" as FE

== Luồng 1: Kết nối ban đầu & Đăng ký LWT ==
ESP -> Broker: 1. Connect MQTT\n(Đăng ký LWT: topic 'trangthai/iot',\npayload 'offline', retain=true)
activate Broker
Broker --> ESP: 2. Connack OK
ESP -> Broker: 3. Publish 'trangthai/iot'\n{status: 'online', retain=true}
Broker -> Web: 4. Forward trạng thái 'online'
activate Web
Web -> DB: 5. UPDATE iot_online = true
Web -> FE: 6. Broadcast WebSocket\n{iot_online: true}
deactivate Web

== Luồng 2: Định kỳ cập nhật mức đầy (chu kỳ 10 giây) ==
loop Mặc định mỗi 10 giây
ESP -> ESP: 7. Đọc khoảng cách thô 'd'\ntừ HC-SR04
ESP -> Broker: 8. Publish 'mucday/loai_rac'\n{distance_cm: d}
Broker -> Web: 9. Forward dữ liệu 'mucday'
activate Web
Web -> Web: 10. Tính % = (H - d) / H \* 100\n& Clamp dữ liệu (0 - 100%)
Web -> DB: 11. UPDATE phan_tram_day_hien_tai
Web -> FE: 12. Broadcast WebSocket\n{thung_rac_id, phan_tram_day}
deactivate Web
end

== Luồng 3: Phát hiện sự cố rớt mạng (cơ chế MQTT LWT) ==
note over ESP: ESP32 đột ngột mất điện / ngắt kết nối
Broker -> Broker: 13. Kiểm tra mất kết nối TCP\n(Ping timeout)
Broker -> Web: 14. Tự động publish LWT\n'trangthai/iot' {status: 'offline'}
deactivate Broker
activate Web
Web -> DB: 15. UPDATE iot_online = false,\nlan_cuoi_online = NOW()
Web -> FE: 16. Broadcast WebSocket\n{iot_online: false}
deactivate Web

@enduml
