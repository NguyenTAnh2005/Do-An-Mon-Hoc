== Luồng 1: Kết nối ban đầu & Đăng ký LWT ==
ESP -> Broker: 1. Connect MQTT\n(Đăng ký LWT)
activate Broker
Broker --> ESP: 2. Connack OK
ESP -> Broker: 3. Publish 'online' retain
Broker -> Web: 4. Forward trạng thái 'online'
activate Web
Web -> DB: 5. UPDATE iot_online = true
Web -> FE: 6. Broadcast WebSocket\n{iot_online: true}
deactivate Web

== Luồng 2: Định kỳ cập nhật mức đầy (chu kỳ 10 giây) ==
loop Mặc định mỗi 10 giây
ESP -> ESP: 7. Đọc khoảng cách d \n HC-SR04
ESP -> Broker: 8. Publish 'fill_level/watse_type'\n{distance_cm: d}
Broker -> Web: 9. Forward dữ liệu 'fill_level'
activate Web
Web -> Web: 10. Tính % = (H - d) / H \* 100\n& Clamp dữ liệu (0 - 100%)
Web -> DB: 11. UPDATE current_fill_level
Web -> FE: 12. Broadcast WebSocket\n{trash_bin_id, fill_percent}
deactivate Web
end

== Luồng 3: Phát hiện sự cố rớt mạng (cơ chế MQTT LWT) ==
note over ESP: ESP32 đột ngột mất điện / ngắt kết nối
Broker -> Broker: 13. Kiểm tra mất kết nối TCP\n(Ping timeout)
Broker -> Web: 14. Tự động publish LWT\n'status/iot' {status: 'offline'}
deactivate Broker
activate Web
Web -> DB: 15. UPDATE iot_online = false,\n iot_last_online = NOW()
deactivate Web
