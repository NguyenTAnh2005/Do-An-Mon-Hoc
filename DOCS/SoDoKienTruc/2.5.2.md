== Luồng 1: Kết nối ban đầu & đăng ký LWT ==
ESP -> Broker: 1. Connect MQTT (đăng ký LWT)
Broker --> ESP: 2. Connack OK
ESP -> Broker: 3. Publish 'online' (retain)
Broker -> Web: 4. Forward trạng thái 'online'
Web -> DB: 5. UPDATE iot_online = true
Web -> FE: 6. Broadcast WS (iot_online: true)

== Luồng 2: Cập nhật mức đầy định kỳ (10 giây) ==
loop Mỗi 10 giây
ESP -> ESP: 7. Đọc khoảng cách d (HC-SR04)
ESP -> Broker: 8. Publish 'mucday' (distance_cm)
Broker -> Web: 9. Forward dữ liệu 'mucday'
Web -> Web: 10. Tính % = (H - d) / H × 100, giới hạn 0-100%
Web -> DB: 11. UPDATE phan_tram_day
Web -> FE: 12. Broadcast WS (thung_rac_id, %)
end

== Luồng 3: ESP32 mất điện / ngắt kết nối (MQTT LWT) ==
Broker -> Broker: 13. Ping timeout (mất kết nối TCP)
Broker -> Web: 14. Tự publish LWT (status: 'offline')
Web -> DB: 15. UPDATE iot_online = false, lan_cuoi_online = NOW()
Web -> FE: 16. Broadcast WS (iot_online: false)
@enduml
